## 📁 Estrutura do Repositório

| Pasta | Conteúdo |
|-------|----------|
| `00_apresentacao/` | Página de apresentação pessoal (HTML + CSS)                         |
| `01_php-into/`     | Páginas de apresntações pessoal e de projetos dinamico(PHP+HTML+CSS)|
| `02_formulario/`   | Página de contatação (com Json ) e outro informando que foi cobutado|
|  `03_pdo/`         | Página de manipulação de dados de banco de dados sql em PHP         |
| `04_sessoes/`      | Página de aprentisagem da variavel do PHP SESSION                   |
|`05_crud/`          | Página com a inplementação todal do crud em php                     |
| `includes/`        | Includes das página(que são função que funciona andes do servidor)  |
| `index.php`        | Página de saudações do criador das páginas                          |
|`sobre.php`         | Página sobre o criador das páginas, a onde ele fala sobre si        |
